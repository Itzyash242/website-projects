# website-projects

This repository contains a responsive landing page website built with HTML, CSS, and JavaScript.

## Features
- Modern hero section with call-to-action buttons
- Services, projects, and about sections
- Responsive mobile navigation
- Clean, premium styling
- Simple JavaScript interaction for the menu and footer year

## Run locally
Open `index.html` in your browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
